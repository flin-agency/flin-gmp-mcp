# Support

Report problems at https://github.com/flin-agency/flin-gmp-mcp/issues or contact
flin@flin.agency. Include the version, operating system, tool name and sanitized
error code. Do not include OAuth secrets, tokens, or private customer data.

Start with health_check, then authenticate if sign-in is required. See README.md
for enabled APIs, permissions, pagination and product limitations.
